# API-011 注文作成

## API情報

| 項目           | 内容           |
| -------------- | -------------- |
| API番号        | API-011        |
| API名          | 注文作成       |
| メソッド       | POST           |
| エンドポイント | `/orders`      |
| 認証           | 必要           |
| Content-Type   | application/json |

---

## 概要

カート内容をもとに注文を作成するためのエンドポイントです。

---

## 処理概要

1. POSTリクエストを受け付ける
2. リクエストボディから `address_id` を取得する
3. カート内容を確認する
4. 金額を計算する
5. `orders` と `order_items` を作成する
6. 注文結果を返却する

---

## Request

### Path Parameter

なし

### Query Parameter

なし

### Request Body

```json
{
  "address_id": "uuid"
}
```

---

## バリデーション

- `address_id` は必須
- カートが空の場合は作成不可
- 配送先住所が存在すること

---

## 処理内容

- カート内容を取得する
- 小計、送料、割引、税額、合計を計算する
- `orders` を作成する
- `order_items` を作成する
- 必要なら在庫を減算する

---

## Response

### HTTP 201 Created

```json
{
  "id": "uuid",
  "order_number": "ORD-20260805-0001",
  "status": "pending",
  "subtotal_amount": 3000,
  "shipping_amount": 500,
  "discount_amount": 0,
  "tax_amount": 350,
  "total_amount": 3850
}
```

### レスポンス項目

| 項目 | 型 | 説明 |
| ---- | -- | ---- |
| id | string | 注文ID |
| order_number | string | 注文番号 |
| status | string | 注文状態 |
| subtotal_amount | number | 小計 |
| shipping_amount | number | 送料 |
| discount_amount | number | 割引額 |
| tax_amount | number | 税額 |
| total_amount | number | 合計金額 |

---

## HTTPステータス

| ステータス | 内容 |
| ---------- | ---- |
| 201        | 作成成功 |
| 400        | 入力不備 |
| 404        | データなし |
| 500        | サーバーエラー |

---

## エラー

### HTTP 400 Bad Request

```json
{
  "message": "address_id は必須です。"
}
```

### HTTP 404 Not Found

```json
{
  "message": "配送先住所が見つかりません。"
}
```

---

## 備考

- `orders` と `order_items` は同一トランザクションで作成する
- 注文確定時に在庫更新を行う
