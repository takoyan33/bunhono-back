# API-009 カート商品の数量更新

## API情報

| 項目           | 内容               |
| -------------- | ------------------ |
| API番号        | API-009            |
| API名          | カート商品の数量更新 |
| メソッド       | PATCH              |
| エンドポイント | `/cart-items/:id`  |
| 認証           | 必要               |
| Content-Type   | application/json   |

---

## 概要

指定したカート商品の数量を更新するためのエンドポイントです。

---

## 処理概要

1. PATCHリクエストを受け付ける
2. `id` を取得する
3. リクエストボディから数量を取得する
4. 数量を検証する
5. `cart_items` テーブルを更新する
6. 更新結果を返却する

---

## Request

### Path Parameter

| 項目 | 型     | 必須 | 説明 |
| ---- | ------ | ---- | ---- |
| id   | string | 必須 | カート商品ID |

### Query Parameter

なし

### Request Body

```json
{
  "quantity": 2
}
```

---

## バリデーション

- `id` は必須
- `quantity` は必須
- `quantity` は 1 以上

---

## 処理内容

- 指定したカート商品を検索する
- 数量を更新する
- 更新後の情報をJSON形式で返却する

---

## Response

### HTTP 200 OK

```json
{
  "id": "uuid",
  "cart_id": "uuid",
  "product_variant_id": "uuid",
  "quantity": 2,
  "created_at": "2026-08-05T00:00:00.000Z",
  "updated_at": "2026-08-05T00:00:00.000Z"
}
```

### レスポンス項目

| 項目              | 型     | 説明 |
| ----------------- | ------ | ---- |
| id                | string | カート商品ID |
| cart_id           | string | カートID |
| product_variant_id | string | 商品バリアントID |
| quantity          | number | 数量 |
| created_at        | string | 作成日時 |
| updated_at        | string | 更新日時 |

---

## HTTPステータス

| ステータス | 内容 |
| ---------- | ---- |
| 200        | 正常終了 |
| 400        | 入力不備 |
| 404        | データなし |
| 500        | サーバーエラー |

---

## エラー

### HTTP 400 Bad Request

```json
{
  "message": "quantity は 1 以上で指定してください。"
}
```

### HTTP 404 Not Found

```json
{
  "message": "カート商品が見つかりません。"
}
```

---

## 備考

- 認証済みユーザーのカートのみ更新可能にする
- 在庫数との整合性チェックを追加する場合がある
