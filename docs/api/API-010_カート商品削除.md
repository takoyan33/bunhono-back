# API-010 カート商品削除

## API情報

| 項目           | 内容             |
| -------------- | ---------------- |
| API番号        | API-010          |
| API名          | カート商品削除   |
| メソッド       | DELETE           |
| エンドポイント | `/cart-items/:id` |
| 認証           | 必要             |
| Content-Type   | application/json |

---

## 概要

指定したカート商品を削除するためのエンドポイントです。

---

## 処理概要

1. DELETEリクエストを受け付ける
2. `id` を取得する
3. `cart_items` テーブルから対象データを削除する
4. 削除結果を返却する

---

## Request

### Path Parameter

| 項目 | 型     | 必須 | 説明 |
| ---- | ------ | ---- | ---- |
| id   | string | 必須 | カート商品ID |

### Query Parameter

なし

### Request Body

なし

---

## バリデーション

- `id` は必須

---

## 処理内容

- 指定したカート商品を検索する
- 対象データを削除する
- 削除結果をJSON形式で返却する

---

## Response

### HTTP 200 OK

```json
{
  "message": "カート商品を削除しました。"
}
```

---

## HTTPステータス

| ステータス | 内容 |
| ---------- | ---- |
| 200        | 正常終了 |
| 404        | データなし |
| 500        | サーバーエラー |

---

## エラー

### HTTP 404 Not Found

```json
{
  "message": "カート商品が見つかりません。"
}
```

---

## 備考

- 認証済みユーザーのカートのみ削除可能にする
- 削除前に所有者確認を行う
