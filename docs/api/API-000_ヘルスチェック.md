# API-000 ヘルスチェック

## API情報

| 項目           | 内容             |
| -------------- | ---------------- |
| API番号        | API-000          |
| API名          | ヘルスチェック   |
| メソッド       | GET              |
| エンドポイント | `/healthcheck`   |
| 認証           | 不要             |
| Content-Type   | application/json |

---

## 概要

APIサーバーが正常に起動しているか確認するためのエンドポイントです。
監視ツールやロードバランサーからの疎通確認にも利用します。

---

## 処理概要

1. GETリクエストを受け付ける
2. サーバーが正常に起動していることを確認する
3. 現在時刻を取得する
4. ステータス情報を返却する

---

## Request

### Path Parameter

なし

### Query Parameter

なし

### Request Body

なし

---

## バリデーション

なし

---

## 処理内容

- サーバーの稼働状態を確認する
- 現在時刻を取得する
- ステータス情報をJSON形式で返却する

---

## Response

### HTTP 200 OK

```json
{
  "status": "OK",
  "message": "API is running.",
  "timestamp": "2026-08-04T14:00:00.000Z"
}
```

### レスポンス項目

| 項目      | 型     | 説明                        |
| --------- | ------ | --------------------------- |
| status    | string | APIの状態                   |
| message   | string | 実行結果メッセージ          |
| timestamp | string | サーバー時刻（ISO8601形式） |

---

## HTTPステータス

| ステータス | 内容           |
| ---------- | -------------- |
| 200        | 正常終了       |
| 500        | サーバーエラー |

---

## エラー

### HTTP 500 Internal Server Error

```json
{
  "message": "サーバーエラーが発生しました。"
}
```

---

## 処理フロー

```text
Client
   │
   │ GET /healthcheck
   ▼
API Server
   │
   ├─ サーバー起動確認
   ├─ 現在時刻取得
   ▼
200 OK
```

---

## 備考

- 認証不要
- データベースへのアクセスは行わない
- サーバーの生存確認（Health Check）を目的としたAPI
- ロードバランサーや監視システムから定期的に呼び出されることを想定
