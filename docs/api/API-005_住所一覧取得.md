# API-005 住所一覧取得

## API情報

| 項目           | 内容             |
| -------------- | ---------------- |
| API番号        | API-005          |
| API名          | 住所一覧取得     |
| メソッド       | GET              |
| エンドポイント | `/addresses`     |
| 認証           | 不要             |
| Content-Type   | application/json |

---

## 概要

住所情報の一覧を取得するためのエンドポイントです。

---

## 処理概要

1. GETリクエストを受け付ける
2. `addresses` テーブルから一覧を取得する
3. 住所一覧を返却する

---

## Request

### Path Parameter

なし

### Query Parameter

なし

### Request Body

なし

---

## バリデーション

なし

---

## 処理内容

- `addresses` テーブルから全件取得する
- 取得結果をJSON形式で返却する

---

## Response

### HTTP 200 OK

```json
[
  {
    "id": "uuid",
    "user_id": "uuid",
    "name": "Taro",
    "postal_code": "100-0001",
    "prefecture": "東京都",
    "city": "千代田区",
    "street": "1-1-1",
    "building": "ABCビル",
    "phone": "090-0000-0000",
    "is_default": true
  }
]
```

### レスポンス項目

| 項目        | 型     | 説明 |
| ----------- | ------ | ---- |
| id          | string | 住所ID |
| user_id     | string | ユーザーID |
| name        | string | 宛名 |
| postal_code | string | 郵便番号 |
| prefecture  | string | 都道府県 |
| city        | string | 市区町村 |
| street      | string | 番地 |
| building    | string | 建物名 |
| phone       | string | 電話番号 |
| is_default  | boolean | デフォルト住所かどうか |

---

## HTTPステータス

| ステータス | 内容 |
| ---------- | ---- |
| 200        | 正常終了 |
| 500        | サーバーエラー |

---

## エラー

### HTTP 500 Internal Server Error

```json
{
  "message": "サーバーエラーが発生しました。"
}
```

```text

   ▼

```
