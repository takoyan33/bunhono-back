# API-008 カート取得

## API情報

| 項目           | 内容             |
| -------------- | ---------------- |
| API番号        | API-008          |
| API名          | カート取得       |
| メソッド       | GET              |
| エンドポイント | `/carts/me`      |
| 認証           | 不要             |
| Content-Type   | application/json |

---

## 概要

ログインユーザーのカート情報を取得するためのエンドポイントです。

---

## 処理概要

1. GETリクエストを受け付ける
2. カート情報を取得する
3. カート内容を返却する

---

## Request

### Path Parameter

なし

### Query Parameter

なし

### Request Body

なし

---

## バリデーション

なし

---

## 処理内容

- カート情報を取得する
- 取得結果をJSON形式で返却する

---

## Response

### HTTP 200 OK

```json
[
  {
    "id": "uuid",
    "user_id": "uuid",
    "created_at": "2026-08-05T00:00:00.000Z",
    "updated_at": "2026-08-05T00:00:00.000Z"
  }
]
```

### レスポンス項目

| 項目       | 型     | 説明 |
| ---------- | ------ | ---- |
| id         | string | カートID |
| user_id    | string | ユーザーID |
| created_at | string | 作成日時 |
| updated_at | string | 更新日時 |

---

## HTTPステータス

| ステータス | 内容 |
| ---------- | ---- |
| 200        | 正常終了 |
| 500        | サーバーエラー |

---

## エラー

### HTTP 500 Internal Server Error

```json
{
  "message": "サーバーエラーが発生しました。"
}
```

---

## 処理フロー

```text
Client
   │
   │ GET /carts/me
   ▼
API Server
   │
   ├─ カート情報取得
   ▼
200 OK
```
