# API-012 注文一覧取得

## API情報

| 項目           | 内容             |
| -------------- | ---------------- |
| API番号        | API-012          |
| API名          | 注文一覧取得     |
| メソッド       | GET              |
| エンドポイント | `/orders`        |
| 認証           | 必要             |
| Content-Type   | application/json |

---

## 概要

ログインユーザーの注文一覧を取得するためのエンドポイントです。

---

## 処理概要

1. GETリクエストを受け付ける
2. 認証ユーザーを確認する
3. `orders` テーブルから一覧を取得する
4. 注文一覧を返却する

---

## Request

### Path Parameter

なし

### Query Parameter

なし

### Request Body

なし

---

## バリデーション

- 認証済みであること

---

## 処理内容

- ログインユーザーの注文を取得する
- 取得結果をJSON形式で返却する

---

## Response

### HTTP 200 OK

```json
[
  {
    "id": "uuid",
    "order_number": "ORD-20260805-0001",
    "status": "pending",
    "total_amount": 3850,
    "created_at": "2026-08-05T00:00:00.000Z"
  }
]
```

### レスポンス項目

| 項目 | 型 | 説明 |
| ---- | -- | ---- |
| id | string | 注文ID |
| order_number | string | 注文番号 |
| status | string | 注文状態 |
| total_amount | number | 合計金額 |
| created_at | string | 作成日時 |

---

## HTTPステータス

| ステータス | 内容 |
| ---------- | ---- |
| 200        | 正常終了 |
| 401        | 認証失敗 |
| 500        | サーバーエラー |

---

## エラー

### HTTP 401 Unauthorized

```json
{
  "message": "認証が必要です。"
}
```

---

## 備考

- 他ユーザーの注文は参照できないようにする
- 必要に応じてページネーションを追加する
