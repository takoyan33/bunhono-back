# API-001 ユーザー一覧取得

## API情報

| 項目           | 内容             |
| -------------- | ---------------- |
| API番号        | API-001          |
| API名          | ユーザー一覧取得 |
| メソッド       | GET              |
| エンドポイント | `/users`         |
| 認証           | 不要             |
| Content-Type   | application/json |

---

## 概要

登録済みユーザーの一覧を取得するためのエンドポイントです。

---

## 処理概要

1. GETリクエストを受け付ける
2. `users` テーブルから一覧を取得する
3. ユーザー一覧を返却する

---

## Request

### Path Parameter

なし

### Query Parameter

なし

### Request Body

なし

---

## バリデーション

なし

---

## 処理内容

- `users` テーブルから全件取得する
- 取得結果をJSON形式で返却する

---

## Response

### HTTP 200 OK

```json
[
  {
    "id": "uuid",
    "name": "Taro",
    "email": "taro@example.com",
    "password": "hashed_password",
    "created_at": "2026-08-05T00:00:00.000Z",
    "updated_at": "2026-08-05T00:00:00.000Z"
  }
]
```

### レスポンス項目

| 項目        | 型     | 説明             |
| ----------- | ------ | ---------------- |
| id          | string | ユーザーID       |
| name        | string | ユーザー名       |
| email       | string | メールアドレス   |
| password    | string | ハッシュ化済みPW |
| created_at  | string | 作成日時         |
| updated_at  | string | 更新日時         |

---

## HTTPステータス

| ステータス | 内容     |
| ---------- | -------- |
| 200        | 正常終了 |
| 500        | サーバーエラー |

---

## エラー

### HTTP 500 Internal Server Error

```json
{
  "message": "サーバーエラーが発生しました。"
}
```

---

## 処理フロー

```text
Client
   │
   │ GET /users
   ▼
API Server
   │
   ├─ users テーブル取得
   ▼
200 OK
```

---

## 備考

- 現在の実装では全カラムを返却する
- 本番運用では `password` を返さない設計を検討する
