# API-006 商品一覧取得

## API情報

| 項目           | 内容             |
| -------------- | ---------------- |
| API番号        | API-006          |
| API名          | 商品一覧取得     |
| メソッド       | GET              |
| エンドポイント | `/products`      |
| 認証           | 不要             |
| Content-Type   | application/json |

---

## 概要

公開中の商品一覧を取得するためのエンドポイントです。

---

## 処理概要

1. GETリクエストを受け付ける
2. `products` テーブルから一覧を取得する
3. 商品一覧を返却する

---

## Request

### Path Parameter

なし

### Query Parameter

なし

### Request Body

なし

---

## バリデーション

なし

---

## 処理内容

- `products` テーブルから全件取得する
- 取得結果をJSON形式で返却する

---

## Response

### HTTP 200 OK

```json
[
  {
    "id": "uuid",
    "name": "T-shirt",
    "description": "sample",
    "slug": "t-shirt",
    "price": 3000,
    "status": "active"
  }
]
```

### レスポンス項目

| 項目 | 型 | 説明 |
| --- | --- | --- |
| id | string | 商品ID |
| name | string | 商品名 |
| description | string | 商品説明 |
| slug | string | URL用識別子 |
| price | number | 価格 |
| status | string | 公開状態 |

---

## HTTPステータス

| ステータス | 内容 |
| ---------- | ---- |
| 200        | 正常終了 |
| 500        | サーバーエラー |

---

## エラー

### HTTP 500 Internal Server Error

```json
{
  "message": "サーバーエラーが発生しました。"
}
```

---

## 処理フロー

```text
Client
   │
   │ GET /products
   ▼
API Server
   │
   ├─ products テーブル取得
   ▼
200 OK
```

---

## 備考

- 公開商品だけ返す場合は `status` 条件を追加する
- 画像やバリエーションは別APIで結合する設計にできる
