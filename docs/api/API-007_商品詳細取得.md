# API-007 商品詳細取得

## API情報

| 項目           | 内容             |
| -------------- | ---------------- |
| API番号        | API-007          |
| API名          | 商品詳細取得     |
| メソッド       | GET              |
| エンドポイント | `/products/:id`  |
| 認証           | 不要             |
| Content-Type   | application/json |

---

## 概要

指定した商品IDの商品詳細を取得するためのエンドポイントです。

---

## 処理概要

1. GETリクエストを受け付ける
2. `id` を取得する
3. `products` テーブルから該当商品を検索する
4. 商品詳細を返却する

---

## Request

### Path Parameter

| 項目 | 型     | 必須 | 説明 |
| ---- | ------ | ---- | ---- |
| id   | string | 必須 | 商品ID |

### Query Parameter

なし

### Request Body

なし

---

## バリデーション

- `id` は必須

---

## 処理内容

- `products` テーブルから `id` で検索する
- 検索結果をJSON形式で返却する

---

## Response

### HTTP 200 OK

```json
[
  {
    "id": "uuid",
    "name": "T-shirt",
    "description": "sample",
    "slug": "t-shirt",
    "price": 3000,
    "status": "active"
  }
]
```

### レスポンス項目

| 項目 | 型 | 説明 |
| --- | --- | --- |
| id | string | 商品ID |
| name | string | 商品名 |
| description | string | 商品説明 |
| slug | string | URL用識別子 |
| price | number | 価格 |
| status | string | 公開状態 |

---

## HTTPステータス

| ステータス | 内容 |
| ---------- | ---- |
| 200        | 正常終了 |
| 500        | サーバーエラー |

---

## エラー

### HTTP 500 Internal Server Error

```json
{
  "message": "サーバーエラーが発生しました。"
}
```

---

## 処理フロー

```text
Client
   │
   │ GET /products/:id
   ▼
API Server
   │
   ├─ id を取得
   ├─ products テーブル検索
   ▼
200 OK
```

---
