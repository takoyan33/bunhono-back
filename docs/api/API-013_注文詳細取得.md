# API-013 注文詳細取得

## API情報

| 項目           | 内容             |
| -------------- | ---------------- |
| API番号        | API-013          |
| API名          | 注文詳細取得     |
| メソッド       | GET              |
| エンドポイント | `/orders/:id`    |
| 認証           | 必要             |
| Content-Type   | application/json |

---

## 概要

指定した注文IDの注文詳細を取得するためのエンドポイントです。

---

## 処理概要

1. GETリクエストを受け付ける
2. `id` を取得する
3. `orders` テーブルから注文を取得する
4. `order_items` を含めて返却する

---

## Request

### Path Parameter

| 項目 | 型     | 必須 | 説明 |
| ---- | ------ | ---- | ---- |
| id   | string | 必須 | 注文ID |

### Query Parameter

なし

### Request Body

なし

---

## バリデーション

- `id` は必須
- 認証済みであること

---

## 処理内容

- `orders` を `id` で検索する
- `order_items` を紐づけて取得する
- 注文詳細をJSON形式で返却する

---

## Response

### HTTP 200 OK

```json
{
  "id": "uuid",
  "order_number": "ORD-20260805-0001",
  "status": "pending",
  "total_amount": 3850,
  "items": [
    {
      "product_name_snapshot": "T-shirt",
      "variant_name_snapshot": "Black / M",
      "unit_price_snapshot": 3000,
      "quantity": 1,
      "line_total": 3000
    }
  ]
}
```

### レスポンス項目

| 項目 | 型 | 説明 |
| ---- | -- | ---- |
| id | string | 注文ID |
| order_number | string | 注文番号 |
| status | string | 注文状態 |
| total_amount | number | 合計金額 |
| items | array | 注文明細 |

---

## HTTPステータス

| ステータス | 内容 |
| ---------- | ---- |
| 200        | 正常終了 |
| 401        | 認証失敗 |
| 404        | データなし |
| 500        | サーバーエラー |

---

## エラー

### HTTP 404 Not Found

```json
{
  "message": "注文が見つかりません。"
}
```

---

## 備考

- 他ユーザーの注文は閲覧できないようにする
- 必要なら配送先や支払い情報も含める
