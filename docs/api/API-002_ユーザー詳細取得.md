# API-002 ユーザー詳細取得

## API情報

| 項目           | 内容             |
| -------------- | ---------------- |
| API番号        | API-002          |
| API名          | ユーザー詳細取得 |
| メソッド       | GET              |
| エンドポイント | `/users/:id`     |
| 認証           | 不要             |
| Content-Type   | application/json |

---

## 概要

指定したユーザーIDのユーザー情報を取得するエンドポイントです。

---

## 処理概要

1. GETリクエストを受け付ける
2. `id` を取得する
3. `users` テーブルから該当レコードを検索する
4. 検索結果を返却する

---

## Request

### Path Parameter

| 項目 | 型     | 必須 | 説明 |
| ---- | ------ | ---- | ---- |
| id   | string | 必須 | ユーザーID |

### Query Parameter

なし

### Request Body

なし

---

## バリデーション

- `id` は必須

---

## 処理内容

- `users` テーブルから `id` で検索する
- 検索結果をJSON形式で返却する

---

## Response

### HTTP 200 OK

```json
[
  {
    "id": "uuid",
    "name": "Taro",
    "email": "taro@example.com",
    "password": "hashed_password",
    "created_at": "2026-08-05T00:00:00.000Z",
    "updated_at": "2026-08-05T00:00:00.000Z"
  }
]
```

### レスポンス項目

| 項目        | 型     | 説明             |
| ----------- | ------ | ---------------- |
| id          | string | ユーザーID       |
| name        | string | ユーザー名       |
| email       | string | メールアドレス   |
| password    | string | ハッシュ化済みPW |
| created_at  | string | 作成日時         |
| updated_at  | string | 更新日時         |

---

## HTTPステータス

| ステータス | 内容     |
| ---------- | -------- |
| 200        | 正常終了 |
| 500        | サーバーエラー |

---

## エラー

### HTTP 500 Internal Server Error

```json
{
  "message": "サーバーエラーが発生しました。"
}
```

---

## 処理フロー

```text
Client
   │
   │ GET /users/:id
   ▼
API Server
   │
   ├─ id を取得
   ├─ users テーブル検索
   ▼
200 OK
```
