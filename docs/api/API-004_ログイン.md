# API-004 ログイン

## API情報

| 項目           | 内容             |
| -------------- | ---------------- |
| API番号        | API-004          |
| API名          | ログイン         |
| メソッド       | POST             |
| エンドポイント | `/users/login`   |
| 認証           | 不要             |
| Content-Type   | application/json |

---

## 概要

登録済みユーザーがログインするためのエンドポイントです。

---

## 処理概要

1. POSTリクエストを受け付ける
2. `email` と `password` を取得する
3. 必須項目を検証する
4. `email` でユーザーを検索する
5. パスワードを照合する
6. ログイン結果を返却する

---

## Request

### Path Parameter

なし

### Query Parameter

なし

### Request Body

```json
{
  "email": "taro@example.com",
  "password": "password123"
}
```

---

## バリデーション

- `email` は必須
- `password` は必須

---

## 処理内容

- `users` テーブルから `email` で検索する
- `bcrypt` でパスワードを照合する
- ログイン成功時はユーザー情報を返す

---

## Response

### HTTP 200 OK

```json
{
  "message": "ログイン成功",
  "user": {
    "id": "uuid",
    "name": "Taro",
    "email": "taro@example.com"
  }
}
```

### レスポンス項目

| 項目    | 型     | 説明           |
| ------- | ------ | -------------- |
| message | string | 実行結果メッセージ |
| user    | object | ログインユーザー |

---

## HTTPステータス

| ステータス | 内容     |
| ---------- | -------- |
| 200        | 正常終了 |
| 400        | 入力不備 |
| 401        | 認証失敗 |
| 404        | ユーザー未存在 |
| 500        | サーバーエラー |

---

## エラー

### HTTP 400 Bad Request

```json
{
  "message": "email と password は必須です"
}
```

### HTTP 404 Not Found

```json
{
  "message": "ユーザーが見つかりません"
}
```

### HTTP 401 Unauthorized

```json
{
  "message": "パスワードが間違っています"
}
```

---

## 処理フロー

```text
Client
   │
   │ POST /users/login
   ▼
API Server
   │
   ├─ email/password を確認
   ├─ users テーブル検索
   ├─ パスワード照合
   ▼
200 OK
```

---

## 備考

- 成功レスポンスに `password` は含めない
- 実運用ではトークン発行処理を追加することが多い
