# API-014 決済情報作成

## API情報

| 項目           | 内容             |
| -------------- | ---------------- |
| API番号        | API-014          |
| API名          | 決済情報作成     |
| メソッド       | POST             |
| エンドポイント | `/payments`      |
| 認証           | 必要             |
| Content-Type   | application/json |

---

## 概要

注文に対する決済情報を作成するためのエンドポイントです。

---

## 処理概要

1. POSTリクエストを受け付ける
2. `order_id` を取得する
3. `provider` や `payment_intent_id` を受け取る
4. 注文の存在を確認する
5. `payments` テーブルに保存する
6. 決済情報を返却する

---

## Request

### Path Parameter

なし

### Query Parameter

なし

### Request Body

```json
{
  "order_id": "uuid",
  "provider": "stripe",
  "payment_intent_id": "pi_xxx"
}
```

---

## バリデーション

- `order_id` は必須
- `provider` は必須
- `payment_intent_id` は必要に応じて必須

---

## 処理内容

- 注文の存在を確認する
- 決済事業者情報を保存する
- `payments` テーブルに登録する
- 決済情報をJSON形式で返却する

---

## Response

### HTTP 201 Created

```json
{
  "id": "uuid",
  "order_id": "uuid",
  "provider": "stripe",
  "payment_intent_id": "pi_xxx",
  "status": "pending",
  "amount": 3850,
  "paid_at": null
}
```

### レスポンス項目

| 項目 | 型 | 説明 |
| ---- | -- | ---- |
| id | string | 決済ID |
| order_id | string | 注文ID |
| provider | string | 決済事業者 |
| payment_intent_id | string | 外部決済ID |
| status | string | 決済状態 |
| amount | number | 金額 |
| paid_at | string/null | 支払日時 |

---

## HTTPステータス

| ステータス | 内容 |
| ---------- | ---- |
| 201        | 作成成功 |
| 400        | 入力不備 |
| 404        | データなし |
| 500        | サーバーエラー |

---

## エラー

### HTTP 400 Bad Request

```json
{
  "message": "order_id は必須です。"
}
```

### HTTP 404 Not Found

```json
{
  "message": "注文が見つかりません。"
}
```

---

## 備考

- 実際の決済処理は外部決済サービス連携を前提とする
- `payments` は注文ごとに 1 件を想定する
