# API-003 ユーザー新規登録

## API情報

| 項目           | 内容             |
| -------------- | ---------------- |
| API番号        | API-003          |
| API名          | ユーザー新規登録 |
| メソッド       | POST             |
| エンドポイント | `/users/add`     |
| 認証           | 不要             |
| Content-Type   | application/json |

---

## 概要

新しいユーザーを登録するためのエンドポイントです。

---

## 処理概要

1. POSTリクエストを受け付ける
2. リクエストボディを取得する
3. 必須項目を検証する
4. パスワードをハッシュ化する
5. `users` テーブルに保存する
6. 作成したユーザーを返却する

---

## Request

### Path Parameter

なし

### Query Parameter

なし

### Request Body

```json
{
  "name": "Taro",
  "email": "taro@example.com",
  "password": "password123"
}
```

---

## バリデーション

- `name` は必須
- `email` は必須
- `password` は必須

---

## 処理内容

- 必須項目を確認する
- `bcrypt` でパスワードをハッシュ化する
- `users` テーブルへ INSERT する
- 作成したユーザーをJSON形式で返却する

---

## Response

### HTTP 201 Created

```json
{
  "id": "uuid",
  "name": "Taro",
  "email": "taro@example.com",
  "password": "hashed_password",
  "created_at": "2026-08-05T00:00:00.000Z",
  "updated_at": "2026-08-05T00:00:00.000Z"
}
```

### レスポンス項目

| 項目        | 型     | 説明             |
| ----------- | ------ | ---------------- |
| id          | string | ユーザーID       |
| name        | string | ユーザー名       |
| email       | string | メールアドレス   |
| password    | string | ハッシュ化済みPW |
| created_at  | string | 作成日時         |
| updated_at  | string | 更新日時         |

---

## HTTPステータス

| ステータス | 内容     |
| ---------- | -------- |
| 201        | 作成成功 |
| 400        | 入力不備 |
| 500        | サーバーエラー |

---

## エラー

### HTTP 400 Bad Request

```json
{
  "message": "name は必須です"
}
```

### HTTP 500 Internal Server Error

```json
{
  "message": "サーバーエラーが発生しました。"
}
```

---

## 処理フロー

```text
Client
   │
   │ POST /users/add
   ▼
API Server
   │
   ├─ 必須項目チェック
   ├─ パスワードハッシュ化
   ├─ users テーブルへ登録
   ▼
201 Created
```

---

## 備考

- `password` は平文で保存しない
- `email` の重複対策はDB制約で担保することを推奨する
